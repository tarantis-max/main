AI Access & Readiness

Shows which AI crawlers can reach a site, and how ready each page is to be found and cited by AI search.

How to read this
robots.txt: Blocked means the site asks this bot not to crawl the page. Compliant bots obey; it is not enforcement. "via *" means the site has no rule for this bot by name, so the catch-all rule applies.
Site coverage: the share of sampled sitemap URLs this bot may crawl under robots.txt.
HTTP probe: the server's actual response to the bot's User-Agent, compared to a normal browser. It cannot detect IP-verified blocks (e.g. Cloudflare bot management), so "allowed" here does not prove the real bot gets through.
Directives: noai, noimageai, noindex found in the X-Robots-Tag header or meta tags.
Purpose: training = collects model training data. search = builds an AI search index. user = fetches a page live when a person asks the AI.
Click a row to see the exact robots.txt rules applied to that bot.
