AI Access & Readiness

Shows which AI crawlers can reach a site, and how ready each page is to be found and cited by AI search.

How to read this
robots.txt: Blocked means the site asks this bot not to crawl the page. Compliant bots obey; it is not enforcement. "via *" means the site has no rule for this bot by name, so the catch-all rule applies.
Site coverage: the share of sampled sitemap URLs this bot may crawl under robots.txt.
HTTP probe: the server's actual response to the bot's User-Agent, compared to a normal browser. It cannot detect IP-verified blocks (e.g. Cloudflare bot management), so "allowed" here does not prove the real bot gets through.
Directives: noai, noimageai, noindex found in the X-Robots-Tag header or meta tags.
Policy: deny = on your deny list in bot_policy.json (foreign-adversary operator, ignores robots.txt, or dataset builder/reseller). Denied bots are never counted as "should be allowed"; if one can still crawl, a robots.txt block is shown at the top. Edit the file to change the list, then restart the app.
Purpose: training = collects model training data. search = builds an AI search index. user = fetches a page live when a person asks the AI.
Click a row to see the exact robots.txt rules applied to that bot.
Institution settings (used by the name, structured data and date checks)
Proof points, banned phrases and approved numbers come from messages.json (edit it, then restart the app).
How this works
Your site and each competitor get the same treatment: the Bot Access check plus a readiness crawl of up to the page limit (same host only, robots.txt respected, 2 workers, 0.5 s delay). Your site is re-crawled with the same limit so the comparison is fair. Competitors are scored without your institution's name checks.
Expect about 2-4 minutes per site at 200 pages. Rank 1 = best. Bold = best value. The latest finished comparison is included in the results bundle.

Keys

Keys are saved to keys.json on this computer only (never in the repo or the results bundle). Get them at console.anthropic.com, platform.openai.com, perplexity.ai (API settings) and aistudio.google.com (Gemini has a free tier). A full run of 40 questions costs roughly a dollar or two per paid provider.
How this works
Each question in questions.json (20 branded, 20 category, from EAB's audit prompts and the admitted-student survey themes) is sent to each provider with web search on. The tool records whether the answer mentions Methodist University, cites methodist.edu, contains the required facts, and whether it confused MU with another "Methodist" school. Category questions are the ones to watch: EAB measured MU at 0-4% on these.
Re-run monthly and compare: branded mention, category mention, citation rate, accuracy. The latest run is included in the results bundle (answers only, never keys).
